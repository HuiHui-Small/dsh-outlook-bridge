# Outlook Bridge for DeepSeek Harness

在 DeepSeek Harness 侧栏打开 Outlook，集中处理邮件、管理日历和查看 Microsoft To Do 计划。顶部 AI 输入栏可以帮你创建计划、安排日程或起草邮件。

[v0.3.0 发布页](https://github.com/HuiHui-Small/dsh-outlook-bridge/releases/tag/v0.3.0) · [功能介绍](#功能介绍) · [本次更新](#本次更新) · [安装](#安装) · [连接账户](#连接-outlook-账户) · [使用方法](#使用方法)

## 功能介绍

| 功能 | 可以做什么 |
| --- | --- |
| 邮件 | 浏览文件夹和「重点 / 其他 / 全部」列表，写邮件、回复、归档或删除。侧栏图标显示收件箱未读数。 |
| 一键已读 | 将当前文件夹的未读邮件批量标为已读，包括尚未加载到列表里的邮件。 |
| AI 邮件助手 | 提炼邮件概要、待处理事项和回复建议，或按你给出的要点生成回复草稿。 |
| Outlook 日历 | 在月视图切换和筛选日历，新建、编辑、拖动或删除可写日历中的日程。 |
| 欢迎页天气 | 未选中邮件时，显示所选地点的今日天气和温度范围，支持使用当前位置或手动搜索城市。 |

## 安装

安装包已在 DeepSeek Harness 桌面端 `0.2.2-rc.1` 的独立配置中验证安装和启动。安装后可先用演示邮件查看界面。

1. 打开 DeepSeek Harness，进入左侧栏的 **插件 → 添加插件**。
2. 将下面的 GitHub Release 安装包地址粘贴到 **包名或地址**，然后点 **安装**。

   ```text
   https://github.com/HuiHui-Small/dsh-outlook-bridge/releases/download/v0.3.0/dsh-outlook-bridge-0.3.0.tgz
   ```

3. 安装完成后点 **立即启用**，再从左侧栏进入 **Outlook**。如果 Harness 提示重启，退出并重新打开应用。

## 连接 Outlook 账户

使用个人 Outlook.com 或 Hotmail 邮箱时，建议先按下文注册自己的 Microsoft Entra 应用。工作或学校账户的授权取决于组织的 Microsoft 365 策略。

1. 在 Outlook 面板点击 **连接 Outlook**，按提示生成设备代码并打开微软登录页。
2. 在微软页面输入设备代码，登录并同意授权。返回 Harness，等待面板加载你的邮箱。
3. 如果选择网页授权方式，登录后按面板提示复制浏览器跳转后的完整地址，粘贴到插件里，再点 **完成登录**。

### 配置自己的 Microsoft Entra 应用

使用 `main` 版本时，可点击 Outlook 顶部的 **流程指引**，在插件里查看以下步骤。

1. 在 [Microsoft Entra 管理中心](https://entra.microsoft.com/) 打开 **应用注册 → 新注册**，选择支持你的 Microsoft 账户类型。个人邮箱请选择包含个人 Microsoft 账户的选项。
2. 复制应用的 **应用程序（客户端）ID**。进入该应用的详情，在 **管理 → 身份验证（预览版） / Authentication (Preview) → 设置** 中启用 **允许公共客户端流**。如果页面名称是 **身份验证**，在 **高级设置** 中查找。若使用网页授权，在 **移动和桌面应用程序** 平台注册重定向 URI `https://login.microsoftonline.com/common/oauth2/nativeclient`。
3. 打开插件的 **Outlook → 设置**，填入客户端 ID。仅支持个人账户的应用，租户可填 `consumers`。同时支持组织和个人账户时可填 `common`。单租户组织应用请填对应的租户 ID。
4. 保存设置后重新连接。组织要求管理员同意时，请由租户管理员处理。可参阅 [Microsoft 设备代码登录文档](https://learn.microsoft.com/zh-cn/entra/identity-platform/v2-oauth2-device-code)。

## 使用方法

以下说明以 GitHub `main` 版本为准。计划看板和 AI 创建计划属于「本次更新」中的源码功能。

[邮件](#邮件) · [日历](#日历) · [计划](#计划) · [顶部 AI 输入栏](#顶部-ai-输入栏) · [界面设置](#界面设置) · [欢迎页天气](#欢迎页天气)

顶部的 **刷新** 会重新同步 Outlook 数据。授权失效时可点 **重新授权**。要切换账号，可以先点 **断开连接**，再用另一个账号连接。

### 邮件

- **查看和筛选。** 点击顶部 **邮件**，在左侧选收件箱、草稿、已发送、存档等文件夹。用 **重点 / 其他 / 全部** 切换列表，点筛选图标可只看未读或按分类查看，点排序箭头可切换最新或最早在前。侧栏 Outlook 图标和收件箱旁显示未读数。
- **写信和回复。** 点 **新邮件**，填写收件人、主题和正文后发送。打开一封邮件时，点正文下方的 **回复**，编辑区会在原文下方展开。
- **管理邮件。** 选中邮件后可存档、删除或切换已读状态。右键邮件还可复制发件人邮箱，或在 Outlook 中打开原邮件。右键文件夹可刷新该文件夹。
- **一键已读。** 先打开目标文件夹，再点工具栏的 **一键已读**。操作范围是当前文件夹的未读邮件，包括尚未出现在列表里的邮件。

**AI 阅读与回复。** 在 Harness 的模型设置中配置默认模型，再打开一封邮件。

1. 点 **AI 阅读邮件** 查看概要、待处理事项和回复建议。
2. 点 **AI 快速回复** 生成草稿。也可以先展开回复，在 **回复要点** 写一句要求，例如「感谢对方，说明周五前给出结果」。
3. 核对并修改草稿，再点 **发送回复**。

### 日历

1. 点击顶部 **日历**。用月份箭头、左侧小日历或 **今天** 跳转日期。点击 **日历筛选** 可展开或收起左侧栏，在那里勾选要显示的日历。右键某个日历可只显示它或显示全部。
2. 点 **新事件** 或双击日期，选择日历，填写标题、起止时间、地点和备注。需要时可以设为全天、添加提醒或填写与会者邮箱，然后点 **保存**。
3. 单击已有日程查看详情。右键可编辑、删除或复制日程标题，右键日期可查看当天日程或新建全天活动。拖动可写日历的日程到另一天，可以调整日期。

### 计划

点击顶部 **计划**。看板里的同一项计划可能出现在多栏，例如今天到期的任务会同时出现在「所有项目」和「今天」。勾选完成后，各栏会同步更新。

| 区域 | 显示内容 |
| --- | --- |
| 分类 | 默认显示截止日期已过的未完成计划，用红字和红线提示。可以切换到「任务」等计划清单，或按已有分类标签查看。 |
| 所有项目 | 当前同步范围内的未完成计划，包括没有截止日期的计划。 |
| 今天 / 明天 | 截止日期是今天或明天的未完成计划。 |
| 已完成 | 最近同步的最多 40 项已完成计划。右侧显示完成时间，可按完成时间或创建时间排序，点 ↑ 或 ↓ 切换方向。 |

1. **添加计划。** 选择清单，填入标题，再点 **添加计划**。普通计划选 **任务**。**Flagged Emails** 是 Microsoft To Do 中用于跟进 Outlook 已标记邮件的清单。
2. **设置截止日期。** 点日期框任意位置打开日历，或点 **今天**、**明天**。也可以输入 `交周报/11.12`，截止日期会设为当年的 11 月 12 日，标题保存为「交周报」。输入 `交周报/2028.11.12` 可指定年份。日期后还有文字时，整段会作为标题保存。
3. **移动或调整。** 把计划拖到 **今天** 或 **明天** 会修改截止日期，从其他栏拖回 **所有项目** 会清除截止日期。拖到 **分类** 栏前，先在下拉菜单里选中目标分类标签。也可以右键直接设为今天、明天或清除截止日期。
4. **完成、恢复或删除。** 勾选计划会移入 **已完成**，在那里取消勾选可以恢复。右键可复制计划标题，或点 **删除计划** 直接删除。关联了原邮件的项目请到 Outlook 管理邮件标记。

### 顶部 AI 输入栏

配置 Harness 默认模型后，在 Outlook 顶部输入一句话，再点 **发送** 或按 Enter。

| 想做的事 | 输入示例 | 结果 |
| --- | --- | --- |
| 添加计划 | `添加计划：明天交周报` | 创建到 Microsoft To Do 的默认「任务」清单，并切到计划页。 |
| 安排日程 | `明天下午3点开会一小时` | 解析日期和时间后创建日程。若只填好了表单，核对后点保存。 |
| 起草邮件 | `给 name@example.com 写一封关于项目进度的邮件` | 打开邮件草稿，核对后手动发送。 |

### 界面设置

点 Outlook 顶部的 **界面**，选择 **邮件**、**日历** 或 **计划**。每个页签可以分别调整主面板、顶部栏、AI 输入栏和该页内容区域的不透明度与模糊度。调整时会即时预览，点 **保存外观** 保留设置。想回到初始样式时，点 **恢复默认** 后再保存。

### 欢迎页天气

进入邮件页，关闭正在阅读的邮件，即可看到欢迎页。点击 **使用当前位置** 并允许定位，或点击 **选择城市** 手动搜索。选好后，可点 **更换城市** 调整地点。天气区会显示地点、当前温度、今日最低与最高温度。

## 常见问题

| 遇到的问题 | 处理方法 |
| --- | --- |
| 登录报 `AADSTS65002` | 注册自己的 Microsoft Entra 应用，在插件设置里填入客户端 ID，再重新授权。 |
| 连接后仍显示演示邮件 | 在微软页面完成登录和同意，再返回 Outlook 面板刷新。 |
| AI 按钮不可用 | 检查 Harness 是否配置了可用的默认模型。 |
| 天气无法获取当前位置 | 允许应用定位，或通过城市搜索手动选择地点。 |
| 找不到计划清单或同步失败 | 确认 Outlook 已连接并授权待办权限，再点 **刷新**。授权范围发生变化时可点 **重新授权**。 |

## 权限与数据

- 邮件、日程和计划通过 Microsoft Graph 访问。插件请求用于资料读取、邮件读写和发送、日历读写以及 Microsoft To Do 的委托权限，并用 `offline_access` 维持登录。连接设置和令牌保存在本机 Harness 的插件数据目录。
- 主动使用 AI 功能时，相关邮件内容或输入的指令会发给 Harness 配置的模型服务。
- 天气由 [Open-Meteo](https://open-meteo.com/) 提供。使用设备定位时，经纬度用于查询天气，并通过 [BigDataCloud](https://www.bigdatacloud.com/geocoding-apis/free-reverse-geocode-to-city-api) 解析地点名称。
